部署到 GitHub Pages（仓库名 Gridfall）
  1. 点页面右上角「下载单文件 HTML」，得到一个 .html 文件，把它改名为 index.html。
  2. 在 GitHub 新建公开仓库，名字填 Gridfall（账号 WRM-FW）。
  3. 把 index.html 上传到仓库根目录并提交。
  4. 打开仓库 Settings → Pages，Build and deployment 选 Deploy from a branch，分支选 main、目录选 / (root)，保存。
  5. 约 1 分钟后访问 https://wrm-fw.github.io/Gridfall/ 即可游玩；该文件也可直接双击离线打开。

规则说明

普通五子棋

15×15，黑先，无禁手，任意方向连成五子或以上（长连）即胜。

国际连珠 Renju（RIF）

黑棋受禁手限制，白棋不受限。黑棋必须恰好五连才胜（五连优先于三三/四四）；白棋五连或长连均胜。黑棋禁手：三三（同时形成两个活三）、四四（同时形成两个四）、长连（六子或以上）。活三按 RIF 9.3 递归判定：延伸点本身是禁手的三不算活三（伪活三）。

RIF 正式开局

临时黑方落第 1 手于天元，双方按 26 种规定开局完成前三手（黑-白-黑，直接开局 13 种 + 间接开局 13 种）；临时白方决定是否交换黑白；执白方落第 4 手；执黑方提出两个第五手候选（须通过禁手检测），执白方选其一落下；执白方落第 6 手后进入正常对弈。

难度

简单 → 一般 → 普通 → 困难 → 极难，逐级变强。极难使用 Alpha-Beta 深搜 + VCF 连续冲四搜索，单手最长约 3.5 秒。

围棋

黑先，可选 9/13/19 路。无气提子、禁着点（不可自杀）、劫争不可立即回提。双方连续停手终局，中国规则数子，黑贴 3.75 子。

说明：正式开局的 26 种形状以固定朝向呈现（直接开局第二手在天元正右，间接开局在右上斜邻）；对局与战绩只保存在当前页面内，刷新后清空。
