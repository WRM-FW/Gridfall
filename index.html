联机开房 →

黑白棋社生成 6 位房间码，中国象棋同理；房主先行，未轮到的一方不能落子。

完整棋规 →

连珠禁手与 26 种正式开局、围棋提子与劫争、象棋将死困毙，都在本地判定。

三种下法 →

棋社与象棋有人机、同屏双人、联机开房；跳棋、军棋为人机或同屏双人。

换方申请 →

联机房主默认执黑（象棋执红）；开局前可申请换方，由对方同意或拒绝。

棋谱回放 →

五子棋 / 连珠全程留谱，赛后逐步回放；悔棋、认输、再来一局都在侧栏。

计时对局 →

五子棋 / 连珠与围棋分别记录黑方、白方用时，换手时自动切换。

分档 AI →

黑白棋社五档，象棋与跳棋三档；军棋电脑执蓝，不设难度档。

双人同屏 →

棋社、象棋、跳棋、军棋都能两个人轮流；不用账号，不用联网。

打开即玩 →

纯网页运行，不下载、不注册。手机和电脑打开同一地址，就能落子。

跳棋 / 军棋 →

跳棋三档 AI；军棋布阵后走铁路、工兵排雷、夺旗，电脑或双人都能开。

2048 →

滑动或方向键合并数字，撤销、步数与本次最高分都在侧栏。

扫雷 →

初级 / 中级 / 高级与自定义雷区；第一击安全，插旗、计时、双击展开。

贪吃蛇 →

21×21 棋盘，红果 +10、金果限时 +30；四档速度，撞墙 / 穿墙两种规则。

推箱子 →

30 关仓库谜题，箱子只能推不能拉；撤销、重开、跳关，21 关起多箱大图。

俄罗斯方块 →

10×20 场地，暂存、下一个与落点预览；四档速度，消行计分逐级加速。

井字棋 →

3×3 棋盘，X 先手；人机三档（困难 minimax 不败）或本地双人。

跳一跳 →

3D 等距跳跃，蓄力落点、连击与风力挑战；三种模式、4 套材质主题。

UNO 联机 →
